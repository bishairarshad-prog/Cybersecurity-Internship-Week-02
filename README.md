# Cybersecurity Internship – Week 02

## Project Overview

This repository contains my Week 02 cybersecurity practical work, focused on Footprinting, Reconnaissance, and Network Scanning.

The practical activities helped me understand how to collect domain information, identify website technologies, examine DNS records, and scan a local network using cybersecurity tools.

## Objectives

- Understand footprinting and reconnaissance.
- Collect domain information.
- Identify website technologies.
- Perform DNS lookups and enumeration.
- Inspect HTTP response headers.
- Detect Web Application Firewalls.
- Perform local network scanning using Zenmap.
- Document practical results with screenshots.

## Tools Used

| Tool | Purpose |
|---|---|
| Kali Linux | Security testing environment |
| WHOIS | Domain information gathering |
| WhatWeb | Website technology detection |
| NSLookup | DNS lookup |
| cURL | HTTP header inspection |
| WAFW00F | WAF detection |
| DNSRecon | DNS enumeration |
| Zenmap | Network scanning and visualization |
