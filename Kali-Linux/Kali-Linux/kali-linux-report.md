# Kali Linux Practical Report

## Week 02 Internship

### Objective
To perform basic network reconnaissance
using Kali Linux tools.

### Tools and Commands

#### 1. WHOIS
Command:
whois networkwalks.com

Purpose:
To collect domain registration information.

#### 2. WhatWeb
Command:
whatweb networkwalks.com

Purpose:
To identify website technologies.

#### 3. nslookup
Command:
nslookup networkwalks.com

Purpose:
To find DNS information and IP address.

#### 4. curl
Command:
curl -I https://networkwalks.com

Purpose:
To inspect HTTP response headers.

#### 5. WAFW00F
Command:
wafw00f networkwalks.com

Purpose:
To identify web application firewall.

#### 6. DNSRecon
Command:
dnsrecon -d networkwalks.com

Purpose:
To perform DNS enumeration.

## Conclusion
Successfully practiced different
network reconnaissance tools using Kali Linux.
